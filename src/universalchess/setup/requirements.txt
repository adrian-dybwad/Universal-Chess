# pip-installed, inside the app's private venv
#
# List only what the application imports. Everything here is fetched from PyPI
# and installed by the postinst as root, so an unused entry is code downloaded
# and run with root's privileges for nothing. Restating another package's
# declared dependency has the same cost: ndjson (declared by berserk) and
# casttube (declared by pychromecast) were listed here and are not, now. bleak
# was too, though only tools/dev-tools/sniffers/pegasus_ble.py ever used it --
# it says to install it by hand -- and it pulls dbus-fast, which has no armv6
# wheel and so was compiled from source on every Pi Zero install. Bluetooth on
# the board does not use bleak; managers/ble.py talks to BlueZ over D-Bus.
# test_dependency_manifest.py enforces this.
berserk
# Reads Bluetooth HID keyboard events from /dev/input/event* for the
# keyboard-control feature (see managers/bt_keyboard.py).
evdev
cairosvg
# Generates the SVG QR code on the CA-install page (web/app.py /ca.pem?qr=1).
# Without it the import fails, the endpoint returns 500, and the page shows a
# broken/missing QR image.
segno
pyserial
spidev
# RPi.GPIO is intentionally NOT pip-installed. On the device the API is provided
# system-wide by the Debian dependency python3-rpi.gpio, which on Trixie is the
# python3-rpi-lgpio shim (RPi.GPIO API over lgpio, installed at
# /usr/lib/python3/dist-packages/RPi/GPIO) and is visible to the venv via
# --system-site-packages. In dev/test it is mocked (tests/conftest.py).
# Listing it here makes pip ignore the shim (whose distribution metadata is named
# "rpi-lgpio", not "RPi.GPIO") and instead build the classic RPi.GPIO C extension
# from source -- which needs python3-dev headers (absent) and does not work on
# current Pi kernels anyway, aborting the entire postinst pip step. Do not re-add.
# Used by the e-paper drivers (epaper/framework/waveshare/epd2in9d.py) to pack
# the framebuffer into the panel's 1bpp buffer with np.packbits -- far faster
# than the per-pixel Python loop on the single-core Pi Zero W. Also provided
# system-wide as python3-numpy by the .deb; listed here so the dev/test venv
# matches the device and does not need to mock numpy.
numpy
# The distribution is "chess"; "python-chess" is a 1.999 shim that contains no
# code and exists only to depend on it. Naming it directly installs one package
# instead of two, and matches the module the code imports.
chess
# Web-UI password auth backend. The code calls pam.pam().authenticate(user, pw)
# from the PyPI "python-pam" module (NOT Debian's "PAM"/PyPAM C extension, whose
# API is incompatible). Required on Python 3.13+ where the stdlib crypt/spwd
# modules used by the older fallback paths were removed. On older OS/Python the
# crypt/spwd fallbacks still work, so this is purely additive.
python-pam
# python-pam 2.0.2 imports `six` at runtime but fails to declare it as a
# dependency, so it must be installed explicitly.
six
