Universal Chess - Install Certificate

Secure setup requires a trusted certificate

I've installed it — go to Universal Chess

Scan the QR code or pick your platform below

This certificate allows your device to trust the connection to Universal Chess and only needs to be installed once.

Download for iOS / iPadOS (.mobileconfig)
  1. Tap Download for iOS / iPadOS (opens in Safari)
  2. Tap Allow when prompted to download the profile
  3. Open Settings → General → VPN & Device Management
  4. Tap the Universal Chess TLS Certificate profile → Install
  5. Go to Settings → General → About → Certificate Trust Settings
  6. Enable full trust for Universal Chess CA
Download for Android (.crt)
  1. Tap Download for Android
  2. Open the downloaded UniversalChess-CA.crt file
  3. Give it a name (e.g., "Universal Chess") and tap OK
  4. You may need to set a screen lock if you haven't already
Download Certificate (PEM)

Option A — Keychain Access (GUI)

  1. Click Download Certificate
  2. Open Keychain Access (Spotlight → "Keychain Access")
  3. Select the login keychain in the sidebar
  4. Go to File → Import Items and select the downloaded UniversalChess-CA.pem
  5. Find the imported certificate, double-click it
  6. Expand Trust, change to Always Trust, close and enter your password

Option B — Terminal (one command) 

security add-trusted-cert -r trustRoot \
  -k ~/Library/Keychains/login.keychain-db \
  ~/Downloads/UniversalChess-CA.pem
Download for Windows (.crt)
  1. Click Download for Windows
  2. Double-click the downloaded UniversalChess-CA.crt file → Install Certificate
  3. Select Local Machine → Place in: Trusted Root Certification Authorities
  4. Click Finish
Download Certificate (PEM)

Debian / Ubuntu / Raspberry Pi OS 

sudo cp UniversalChess-CA.pem \
  /usr/local/share/ca-certificates/UniversalChess-CA.crt
sudo update-ca-certificates

Fedora / RHEL / CentOS 

sudo cp UniversalChess-CA.pem \
  /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

Browsers using NSS (Firefox, Chromium on some distros) maintain a separate trust store and will need the cert imported via their settings UI as well.
